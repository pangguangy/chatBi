# 项目说明文档文字要点（对应主办方模板）

> 供撰写《项目说明文档 PDF》直接取用；可粘贴关键代码片段与系统流程图。

## 1. 作品背景

传统制造业经营数据分散在订单、生产计划、实绩、质量、能耗等多张表中，管理者需要
人工写 SQL 或依赖 IT 人员才能取数，效率低、门槛高，异常发现滞后。本作品面向
「制造业运营态势」场景，基于官方模拟经营数据集构建 Chat-BI Agent，让管理者用
**自然语言直接问数**，系统自动完成取数、绘图、日报与异常归因，实现"问数即所得、
异常可溯源"。

## 2. 核心功能

- **自然语言问数**：覆盖产量、订单、质量缺陷、能耗、达成率、延期六类业务问题。
- **多表关联分析**：dim 维表（车型/产线/客户）与 fact 事实表（订单/计划/实绩/缺陷/能耗）
  多表 JOIN，支持业务关联（同车型+同时间窗口）。
- **图表自动生成**：根据问题与结果自动选择柱状图 / 折线图 / 表格 / 文字摘要。
- **运营日报 / 月报**：输入月份或日期范围，一键生成含产量、质量、能耗、延期概览的态势日报。
- **异常解释与溯源**：对质量、能耗、延期、班次效率、停线五类异常给出数据依据，
  并**写明用到哪些数据表、哪些字段**。

## 3. 实现方式（技术架构）

- **技术栈**：Python + LangGraph + Streamlit + SQLite + DeepSeek API。
- **Agent 状态机**：LangGraph 构建任务规划节点、SQL 执行节点、SQL 修正节点、
  图表节点、报告节点、异常溯源节点、汇总节点，以条件边实现重试循环与意图分流。
- **Text-to-SQL**：DeepSeek 依据数据库 schema 与表关系生成 SQL；
- **自动修正重试**：SQL 报错时，Agent 将报错信息回传给 DeepSeek 自动修正 SQL，重试上限 3 次，
  并内置确定性 SQL 库作为兜底，保证离线也能演示。
- **图表**：matplotlib 无界面渲染，色盲友好配色，中文标签。
- **前端**：Streamlit 页面展示提问、执行过程、SQL、结果表格、图表、日报、溯源文本。

> `agent_graph.py`（图构建 + 节点）、`tools/sql_tool.py`（SQL 执行 + 兜底）、
> `tools/anomaly_tool.py`（异常溯源）、`db_init.py`（数据导入）。

## 4. 平台 / 工具情况

- 作品实现方式：**代码开发**。
- 推荐平台/工具使用情况：**未使用推荐平台或工具**。
- 其他平台/模型说明：**LangGraph+Streamlit，调用 DeepSeek API**。
- 大模型：DeepSeek（默认 deepseek-chat，可切换 deepseek-reasoner）。

## 5. 数据与知识库说明

- 使用官方提供的模拟制造业经营数据集（无真实商密、无个人信息）。
- 数据时间范围 2026-01-01 ~ 2026-06-30。
- 结构：dim 维表（车型/产线/客户）+ fact 事实表（订单/计划/实绩/缺陷/能耗）+ 问题集。
- 知识库 = 数据字典 + 表关系说明（主外键 + 业务关联）+ 预置异常规则，
  内嵌为 schema Prompt 与异常检测 SQL，不依赖外部知识库平台。
- 补充材料另附《数据表字典》与《数据集说明文件》。

## 6. 运行 / 访问方式

- 本地：`pip install -r requirements.txt` → `python db_init.py` → `streamlit run app.py`。
- 在线：部署 HuggingFace Spaces（Streamlit SDK），提交 GitHub 代码仓库，获取公开访问链接。

## 7. 创新点

1. **LangGraph 状态机 + 自动修正重试**：规划、工具调用、报错驱动的 SQL 自我修复形成闭环，
   提升 Text-to-SQL 鲁棒性。
2. **确定性 SQL 兜底库**：LLM 不可用或出错时自动降级，保证演示与评审稳定可用。
3. **可解释溯源**：每个异常结论强制附带"数据表 + 字段"依据，满足审计与业务信任需求。
4. **意图分流**：普通问数、异常归因、日报生成三种意图自动路由到不同处理链路。

## 8. 应用价值

- 降低取数门槛：管理者零 SQL 基础即可自助问数，缩短决策取数周期。
- 主动发现异常：质量、能耗、延期、班次效率、停线五类异常自动识别并给出依据。
- 可追溯可信：结论可回溯到具体数据表与字段，便于验证与治理。
- 轻量可移植：纯 Python 工程，本地与 HuggingFace Spaces 均可运行。

## 9. 测试效果

- 公开问题集（Q_PUB_001~010）全部给出与参考答案一致的结论；
- 隐藏问题集（Q_HID_001~005）按参考答案要点均可命中（缺陷率上升、C005 延期归因、
  L002 能耗效率异常、L003 夜班效率低、M003 质量与交付双异常）；
- SQL 错误修正重试链路可复现；离线模式下全流程可演示。
