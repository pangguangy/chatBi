# 演示录制剧本 & 提交清单

## 一、启动（Windows，务必用完整路径）

`python` 在本机指向 Windows 商店占位符会"没反应"，用真实 Python 的完整路径：

```bash
cd "C:\Users\86135\制造业运营态势ChatBI-Agent"
C:\Users\86135\AppData\Local\Programs\Python\Python312\python.exe -m streamlit run app.py
```

浏览器打开 `http://localhost:8501`。

## 二、两种运行模式

| | 离线模式 | 在线模式（DeepSeek） |
|---|---|---|
| 前提 | 直接启动 | 建 `.env` 填 `DEEPSEEK_API_KEY=sk-你的key` |
| 侧边栏 | 「未配置 API Key，离线模式」 | 「已配置 API Key（模型 deepseek-chat）· LLM 驱动」 |
| 总结文字 | 末尾「仅展示数据结果」 | 一段自然语言 |

> 配置 Key：复制 `.env.example` 为 `.env`，填入自己的 `DEEPSEEK_API_KEY`（`.env` 已被
> `.gitignore` 忽略，不会泄露）。获取地址 https://platform.deepseek.com。

## 三、录屏剧本（Win+G 或 Win+Shift+R 录屏，约 6~8 分钟）

### 第一段 · 离线模式（3 分钟）

| 顺序 | 点示例问题按钮 | 指屏幕讲什么 |
|---|---|---|
| 开场 | —— | 指标题 + 侧边栏「离线模式也能跑全流程」+ 11 张表 |
| ① | 各车型6月总产量 | SQL→表格→柱状图，点开「🧭 执行过程」看轨迹 |
| ② | M003缺陷率相对5月是否上升 | **折线图**，环比约 3 倍 |
| ③ | 哪条产线单车电耗异常升高 | **核心**：指「🔍异常溯源」结论 + 数据表/字段依据 |
| ④ | 生成6月运营日报 | 压轴：4 板块 + 5 类异常一屏看全 |

### 第二段 · 在线模式（2 分钟，可选）

1. 回终端 `Ctrl + C` 停掉；
2. 建好 `.env` 并填 `DEEPSEEK_API_KEY`；
3. 重启，侧边栏变「LLM 驱动」，指出来；
4. **再问一遍「各车型6月总产量」**，对比：总结从「仅展示数据结果」变成自然语言，轨迹显示「DeepSeek 生成 SQL」。

### 第三段 · 收尾（30 秒）

打开 `agent_graph.py`，指 `fix_sql_node` 与 `MAX_SQL_RETRY = 3`：
「SQL 出错会依据报错自动修正并重试，最多 3 次」。
