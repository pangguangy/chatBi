## 五、Agent 硬性技术要求

| 用例ID | 测试内容 | 预期行为 |
|---|---|---|
| TC-401 | 任务规划 | 用户提问后，Agent 输出「执行步骤」轨迹：规划 → 执行 SQL → 生成图表 → 汇总 |
| TC-402 | 工具调用 | 分别调用 SQL 执行工具、图表生成工具、异常溯源工具（日志可见） |
| TC-403 | SQL 自动修正重试 | 对含错误 SQL 的场景，Agent 依据报错自动生成修正 SQL 并重试；≤3 次后兜底到启发式 SQL 或给出失败说明 |
| TC-404 | 离线降级 | 未配置 API Key 时，Agent 仍可完成图表/日报/溯源（内置 SQL 库） |

## 六、边界与异常输入

| 用例ID | 输入 | 预期行为 |
|---|---|---|
| TC-501 | 空问题 / 无关闲聊 | 提示换一种问法，不崩溃 |
| TC-502 | 非法 SQL（如 DELETE） | 只读校验拦截，报「仅允许 SELECT」 |
| TC-503 | 数据目录不存在 | db_init 明确报错路径，不静默失败 |
| TC-504 | 含 `__MACOSX` 与 `.DS_Store` 的目录 | 正确忽略，只导入有效 csv |

## 验收标准

- 15 个公开 + 隐藏问题（Q_PUB_001~010、Q_HID_001~005）全部能给出与参考答案一致的结论；
- 每个异常结论均附「数据表 + 字段」溯源说明；
- SQL 报错时能看到重试轨迹与最终成功结果；
- 页面完整展示：提问、执行 SQL、结果表格、图表、日报、溯源文本。
