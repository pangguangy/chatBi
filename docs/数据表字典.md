# 数据表字典

> 补充材料①：制造业运营态势 Chat-BI 模拟数据集字段字典。
> 数据时间范围：2026-01-01 ~ 2026-06-30；全部为模拟数据，无真实商密、无个人信息。

## dim_model（车型维表）

| 字段 | 类型 | 说明 |
|---|---|---|
| model_id | TEXT | 车型ID，主键（M001~M008） |
| model_name | TEXT | 车型名称（轻卡A型 … 专用车H型） |
| product_series | TEXT | 产品系列（轻卡/中卡/重卡/专用车） |
| vehicle_type | TEXT | 车辆类型（燃油车/新能源车） |
| standard_cycle_minutes | INTEGER | 标准单车生产节拍（分钟） |
| standard_energy_kwh | INTEGER | 单车理论电耗（kWh） |
| launch_year | INTEGER | 上市年份 |

## dim_workshop_line（产线维表）

| 字段 | 类型 | 说明 |
|---|---|---|
| line_id | TEXT | 产线ID，主键（L001~L008） |
| line_name | TEXT | 产线名称（总装一线、焊装一线…） |
| workshop | TEXT | 所属车间 |
| shift_type | TEXT | 班次类型（两班制） |
| designed_daily_capacity | INTEGER | 设计日产能 |
| main_model_series | TEXT | 主要生产系列 |

## dim_customer（客户维表）

| 字段 | 类型 | 说明 |
|---|---|---|
| customer_id | TEXT | 客户ID，主键（C001~C060） |
| customer_name | TEXT | 客户名称（已匿名化） |
| customer_type | TEXT | 客户类型（经销商/大客户/物流企业/工程客户/政府事业单位） |
| region | TEXT | 区域（华东/华中/华南/华北/西南/西北） |
| priority_level | TEXT | 客户优先级（高/中/低） |

## fact_orders（订单事实表）

| 字段 | 类型 | 说明 |
|---|---|---|
| order_id | TEXT | 订单ID，主键 |
| customer_id | TEXT | 客户ID，关联 dim_customer |
| model_id | TEXT | 车型ID，关联 dim_model |
| order_date | TEXT | 下单日期（YYYY-MM-DD） |
| planned_delivery_date | TEXT | 计划交付日期 |
| actual_delivery_date | TEXT | 实际交付日期（未交付为空） |
| order_quantity | INTEGER | 订单数量 |
| delivered_quantity | INTEGER | 已交付数量 |
| order_status | TEXT | 订单状态（已交付/延期交付/生产中） |
| delay_days | INTEGER | 延期天数（未交付为空） |

## fact_production_plan（生产计划事实表）

| model_id | TEXT | 车型ID，关联 dim_model |

## fact_quality_defects（质量缺陷事实表）

## schema_relationships（表关系元数据）

| 字段 | 说明 |
|---|---|
| source_table / source_key | 主表与主键 |
| target_table / target_key | 从表与外键 |
| relationship_type | 关系类型（1:N / 1:1 / 业务关联） |
| description | 关系描述 |

| related_tables | 主要相关表 |
