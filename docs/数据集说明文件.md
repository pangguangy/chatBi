# 数据集说明文件

> 补充材料②：制造业运营态势 Chat-BI 模拟数据集说明。

## 1. 数据定位

本数据集为赛事方发布的**模拟**制造业经营数据集，覆盖订单、生产计划、生产实绩、
质量缺陷、能源消耗、车型、产线、客户等业务对象。**数据时间范围 2026-01-01 ~ 2026-06-30**。
数据为程序模拟生成，**不含任何真实商业秘密与个人信息**。

## 2. 数据规模

| 数据对象 | 表名 | 记录数（约） |
|---|---|---|
| 车型 | dim_model | 8 |
| 产线 | dim_workshop_line | 8 |
| 客户 | dim_customer | 60 |
| 订单 | fact_orders | 数百 |
| 生产计划 | fact_production_plan | 数千 |
| 生产实绩 | fact_production_actual | 数千 |
| 质量缺陷 | fact_quality_defects | 数千 |
| 能耗 | fact_energy_usage | 数千 |

（以 db_init.py 实际导入行数为准。）

## 3. 数据结构

「维表 + 事实表 + 问题集」星型/雪花结构：

- **维表**：dim_model、dim_workshop_line、dim_customer；
- **事实表**：fact_orders、fact_production_plan、fact_production_actual、
  fact_quality_defects、fact_energy_usage；
- **元数据**：schema_relationships（主外键与业务关联）、question_public / question_hidden（问题集）。

## 4. 主外键关系（摘要）

- dim_customer.customer_id → fact_orders.customer_id（1:N）
- dim_model.model_id → fact_orders / fact_production_plan / fact_production_actual /
  fact_quality_defects / fact_energy_usage（1:N）
- dim_workshop_line.line_id → fact_production_plan / fact_production_actual /
  fact_quality_defects / fact_energy_usage（1:N）
- fact_production_plan.plan_id → fact_production_actual.plan_id（1:1）
- 业务关联（非外键）：订单延期 ↔ 生产实绩 / 质量缺陷（按 车型+时间窗口），
  产量 ↔ 能耗（按 产线+车型+日期）。

## 5. 预置业务异常（评测线索）

1. 2026-06，M003（中卡C型）在 L002（焊装一线）质量异常，集中于「焊装-焊点虚焊」；
2. 2026-06-10 ~ 06-24，L002 单车电耗明显升高；
3. 2026-06，客户 C005 的 M003 订单集中延期；
4. L003（总装二线）夜班达成率持续低于白班；
5. 2026-04-08 ~ 04-18，L005（总装三线）停线时长偏高。

## 6. 使用方式

- 本工程 `db_init.py` 自动读取 csv 导入 SQLite（**忽略 __MACOSX 目录**）；
- 问题集（question_public/question_hidden）用于自测与统一评审；
- 数据字典见《数据表字典》，表关系见《表关系说明》。
